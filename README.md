#  FileService

A simple file management service built with Java 17 and Spring Boot. The application receives files over HTTP (for example, using Postman), saves them in a PostgreSQL database, and stores metadata such as file name, size, type, and upload date.

---

##  Project Description

**FileService** is a REST-based microservice that allows users to upload files via HTTP. It stores file content and metadata (filename, upload date, type, and size) in a PostgreSQL database. The system is containerized using Docker and works in tandem with a PostgreSQL instance.

##  Getting Started

### 1. Build the Docker image for the FileService:

```bash
docker build -t filemanager:1.0.0.R .
```

### 2. Start the application:

```bash
docker-compose up
```

*The PostgreSQL image is already set up in **`docker-compose.yml`**. The FileService image must be built manually.*

##  Database Schema

Single table: `files`

Columns:

 The table is automatically created at runtime using Hibernate, thanks to the configuration spring.jpa.hibernate.ddl-auto=update.


- `id` – autogenerated ID
- `file_name` – the name of the uploaded file
- `file_type` – file MIME type (e.g., `image/png`, `text/plain`)
- `upload_date` – timestamp of the upload
- `file_data` – the byte array containing the file's content

## 🔧 REST Endpoints

| Method | Endpoint                      | Description                 |
| ------ | ----------------------------- | --------------------------- |
| POST   | `/files/upload`               | Uploads a file              |
| PUT    | `/files/update`               | Updates a file if it exists |
| DELETE | `/files/delete/{id}`          | Deletes a file by ID        |
| GET    | `/files/download/name/{name}` | Downloads file by name      |

---

## 🔍 Notable Classes

### FileResponseDTO

- A DTO for sending file metadata to clients (without including file data)
- Fields: `fileName`, `fileSize`, `fileType`, `uploadDate`

### GlobalExceptionHandler

- Handles exceptions globally using `@RestControllerAdvice`
- Handles: `FileNotFoundException`, `FileSaveException`, generic `Exception`

### FileServiceFacade

- A simple facade class to combine file upload and response services
